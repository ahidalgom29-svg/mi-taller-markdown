## 1. Requisitos y Herramientas

* **Sistema Operativo**: Ubuntu Server
* **Control de Versiones**: Git
* **Plataforma**: GitHub
* *Editor de texto*: `nano`

## 2. Trabajo en Git

1. Comprobar los archivos modificados en el área de trabajo:

1. `git status`
2. `git add guia.md`
3. `git commit -m "Mensaje"`
4. `git push origin main`

## 3. Resumen de comandos

| Comando | Función |
| `git status`| Muestra el estado del workspace |
| `git add` | Mueve archivos al staging area |
| `git commit` | Registra los cambios en el repositorio |
| `git push` | Envía commits a la rama remota |
